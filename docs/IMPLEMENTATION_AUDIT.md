## 已确定的实现差异

- 发送事件的source_seq、首次/末次观测monotonic、epoch、提示词hash、profile版本、activity/cancel序号保存在同一预留事务的audit.metadata中，与attempt_id关联；未为这些字段另改数据库列，schema仍为1。
- 重启将模式降到OBSERVE，并保留显式暂停/目标消失状态；未决发送始终优先恢复为PAUSED_UNCONFIRMED。
- 自定义提示词禁止首尾空白，避免解析器裁剪终端尾部填充空格后无法精确核对。
- API重连时检查绑定进程存活；临时由工具子进程占据前台不会直接判定目标已退出。可恢复错误出现及实际输入之前仍校验完整TTY/前台身份。
- Darwin非控制终端的tcgetpgrp实测返回ENOTTY，改用/bin/ps的内核tpgid快照，并校验PID/PGID/TTY精确匹配；没有省略前台组检查。
- SDK全局App回调在断开时按connection移除；通知异常使连接失效并触发重连。真实试跑发现的问题已经补上回归。
- 补齐SDK旧cookie遭401拒绝后的单次刷新；认证仍在线程执行并复用未结束任务。9项新增回归通过；真实Unix socket探测未产生401，不能据此声称真实刷新分支已验收。
